# Crisp Icons Free

42 free rounded, bold game UI icons in white and dark, as 64 px PNG and SVG, with a one-line lookup helper (CrispIcons.tex("coin")) and a searchable icon browser scene.

Free sampler of Crisp Icons: https://anipixels.itch.io/crisp-icons
Demo scene: `res://addons/crisp_icons_free/demo/icon_browser.tscn`
Documentation: https://github.com/Anipixels/crisp-icons-free
